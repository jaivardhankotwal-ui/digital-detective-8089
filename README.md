## Assignment Overview

This project is structured as a sequential series of hands-on technical investigations ("missions") designed to explore how personal computers operate at hardware, operating system, and network levels, with documented terminal activities, Python implementations, and Git version control practices.

Each mission was investigated, documented, and committed separately in sequence to maintain clear version history and ensure reproducible learning.
